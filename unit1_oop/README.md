I started the program by creating the Animal parent class, which contained common attributes such as a name and species, along with a method used to display basic information. A Dog child class was then created that inherited from Animal. The child class extended the parent by adding breed and achievement information while also overriding the display_info() method to provide more detailed output.

A namespace demonstration function was implemented to show the difference between class and instance namespaces. The demonstration accessed a class variable through both the class itself and object instances. Additional attributes were added to a single object after creation to show how instance namespaces differ between objects. The __dict__ attribute was used to inspect both object and class namespaces.

A copying demonstration function was also developed to compare shallow and deep copying. The copy() function was used to create a shallow copy, while deepcopy() was used to create a deep copy. Changes were then made to nested dictionary data within the original object to show how shallow copies share references to nested objects while deep copies create completely independent copies.
